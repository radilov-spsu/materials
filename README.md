# Материалы курсов

Исходники сайта с лекциями: **https://radilov-spsu.github.io/materials/**

Читать удобнее на сайте — там поиск по всему тексту лекций, оглавление и
рендер диаграмм. Этот репозиторий нужен, чтобы материалы правились как код.

## Структура

```
docs/
├── index.md                     главная сайта
├── ooad/                        объектно-ориентированный анализ и проектирование
│   ├── index.md                 о курсе и программа
│   ├── lectures/                8 лекций
│   ├── self-study/              9 материалов для самостоятельной работы
│   └── labs.md
└── parallel-programming/        технологии параллельного программирования
mkdocs.yml                       конфигурация сайта и меню
requirements.txt                 версии зафиксированы намеренно
```

## Правка

Кнопка-карандаш на любой странице сайта открывает её исходник здесь.
После push в `main` сайт пересобирается сам — минуту-две.

Локальный предпросмотр с автообновлением:

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
mkdocs serve      # http://127.0.0.1:8000
```

Перед push полезно прогнать так же, как это делает CI:

```bash
mkdocs build --strict    # битая ссылка = ошибка сборки
```

## Добавить лекцию

1. Положить файл в `docs/<курс>/lectures/`.
2. Добавить строку в `nav` в `mkdocs.yml` — без неё страница соберётся,
   но в меню не появится.

Диаграммы пишутся блоком ` ```mermaid ` и рендерятся на сайте сами.
