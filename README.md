# Материалы курсов

Публичный репозиторий: лекции, условия работ и разбираемые примеры.

| Папка | Курс |
|---|---|
| [`ooad/`](ooad/) | Объектно-ориентированный анализ и проектирование |
| [`parallel-programming/`](parallel-programming/) | Технологии параллельного программирования |

Внутри каждого курса:

```
lectures/   слайды и конспекты лекций
labs/       условия лабораторных работ
examples/   разбираемые на парах примеры кода
```

## Как получить репозиторий для сдачи работ

Сделайте Pull Request в репозиторий
[**enroll**](https://github.com/radilov-spsu/enroll) этой же организации —
там пошаговая инструкция. Репозиторий выдаётся один на все курсы.
