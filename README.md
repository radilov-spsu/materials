# Материалы курса

Публичный репозиторий с лекциями, заданиями и полезными ссылками.

## Структура

```
lectures/   — слайды и конспекты лекций
labs/       — условия лабораторных работ
examples/   — разбираемые на парах примеры кода
links.md    — литература и полезные ресурсы
```

## Как получить личный репозиторий для сдачи работ

Сделайте Pull Request в репозиторий **enroll** этой же организации —
там пошаговая инструкция в README.
