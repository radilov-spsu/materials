# Лабораторные работы

Условия работ появятся здесь по мере чтения курса.

Работа сдаётся в личном репозитории: ветка `Parallel/lab-XX`,
Pull Request в `main`. Задание приходит issue'ом в ваш репозиторий — там же
дедлайн.

!!! info "Ещё нет репозитория?"

    [Заполните форму регистрации](https://github.com/radilov-spsu/enroll/issues/new?template=enrollment.yml)
    — три поля, репозиторий выдаётся один на все предметы.
