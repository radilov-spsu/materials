## Как проходит сдача работ

Работы сдаются в личном приватном репозитории, который выдаётся один на все
предметы. Чтобы его получить, заполните форму регистрации — это три поля.

[Записаться на курс](https://github.com/radilov-spsu/enroll/issues/new?template=enrollment.yml){ .md-button .md-button--primary }
[Как это устроено](https://github.com/radilov-spsu/enroll){ .md-button }

Внутри репозитория — папка на каждый курс. Работа сдаётся через Pull Request:
так замечания привязываются к конкретным строкам кода, а история сдач видна
целиком.

## Нашли ошибку в материалах?

У каждой страницы справа сверху есть карандаш — он открывает исходный текст на
GitHub. Исправление присылайте Pull Request'ом, это засчитывается как активность
на курсе.
