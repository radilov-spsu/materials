# Лабораторная работа 2 — заготовка

Стартовый проект к лабораторной [«Строитель: один процесс — много
представлений»](../../labs/02-stroitel-protsess-i-predstavlenie.md).
Здесь лежит код этапа 0: генератор подземелья, который **одновременно** обходит план
и форматирует ASCII-карту.

## Как забрать себе

Скопируйте содержимое этой папки в свою работу — целиком, вместе с `tests/`:

```bash
git clone --depth 1 https://github.com/radilov-spsu/materials.git /tmp/materials
cp -r /tmp/materials/OOP/examples/DungeonBuilder/. <ваш-репозиторий>/OOP/lab-02/
```

Без git: на [странице материалов](https://github.com/radilov-spsu/materials)
**Code → Download ZIP**, распаковать, взять папку `OOP/examples/DungeonBuilder`.

Развёрнутая заготовка — ваш **первый коммит**, до единой собственной правки.
Тогда в истории видно, что написали вы, а что было дано.

## Как запустить

```bash
dotnet run --project src/DungeonBuilder      # печатает карту подземелья
dotnet test                                  # тесты
```

Нужен .NET SDK 8.0 или новее. Если стоит только .NET 9/10, запуск всё равно
сработает:

```bash
DOTNET_ROLL_FORWARD=LatestMajor dotnet run --project src/DungeonBuilder
DOTNET_ROLL_FORWARD=LatestMajor dotnet test
```

## Структура

```
src/DungeonBuilder/
    Program.cs              точка входа
    DungeonGenerator.cs     ← код этапа 0, с него начинаете
    Domain/DungeonPlan.cs   план подземелья: комнаты, коридоры (менять можно)
    Domain/GameWorld.cs     заготовка продукта для WorldBuilder (этап 1)
    Domain/Item.cs          заготовка предмета для этапа 3
tests/DungeonBuilder.Tests/
    DungeonGeneratorTests.cs   два примера; остальные пишете вы
```

## Порядок работы

1. Развернуть заготовку, проверить `dotnet run` и `dotnet test` — это первый коммит.
2. Дальше по этапам задания, **каждый этап — отдельный коммит**:
   `этап 1: распорядитель и два строителя`, `этап 2: строитель статистики`, и так далее.
3. Для этапа 2 понадобится `git diff --stat` коммита — приложить в отчёт.
4. Отчёт писать вместо содержимого этого файла.

## Шаблон отчёта

- **Вариант** — номер, вселенная, третий строитель, предмет.
- **Этап 0** — список шагов обхода; что относится к процессу, что к представлению;
  ответ про JSON.
- **Этап 1** — почему `GetResult()` не в общем интерфейсе.
- **Этап 2** — `git diff --stat` коммита, подтверждающий, что распорядитель не тронут.
- **Этап 3** — чем текучий строитель отличается от строителя GoF; где проверяются инварианты.
- **Этап 4** — таблица сравнения и ответ «где строитель не нужен».
- **Диаграммы** — классов и последовательности, в Mermaid.
- **Чем платим** — по абзацу на каждый из двух строителей.
