# Лабораторная работа 3 — заготовка

Стартовый проект к лабораторной [«Прототип: создание копированием»](../../labs/03-prototip-sozdanie-kopirovaniem.md).
Здесь лежит код этапа 0: каждый вид врага — отдельный класс, отличающийся
от соседнего только числами.

## Как забрать себе

Скопируйте содержимое этой папки в свою работу — целиком, вместе с `tests/`:

```bash
git clone --depth 1 https://github.com/radilov-spsu/materials.git /tmp/materials
cp -r /tmp/materials/OOP/examples/EnemyPrototypes/. <ваш-репозиторий>/OOP/lab-03/
```

Без git: на [странице материалов](https://github.com/radilov-spsu/materials)
**Code → Download ZIP**, распаковать, взять папку `OOP/examples/EnemyPrototypes`.

Развёрнутая заготовка — ваш **первый коммит**, до единой собственной правки.
Тогда в истории видно, что написали вы, а что было дано.

## Как запустить

```bash
dotnet run --project src/EnemyPrototypes      # спавн волны из подклассов
dotnet test                                   # тесты
```

Нужен .NET SDK 8.0 или новее. Если стоит только .NET 9/10, запуск всё равно
сработает:

```bash
DOTNET_ROLL_FORWARD=LatestMajor dotnet run --project src/EnemyPrototypes
DOTNET_ROLL_FORWARD=LatestMajor dotnet test
```

## Структура

```
src/EnemyPrototypes/
    Program.cs                 точка входа
    Domain/Enemy.cs            ← код этапа 0: иерархия подклассов
    Domain/Equipment.cs        экипировка и модификаторы — вложенный уровень для этапа 2
    WaveSpawner.cs             спавнер, знающий все конкретные классы
    enemies.json               заготовка конфигурации для этапа 3 (пока не используется)
tests/EnemyPrototypes.Tests/
    EnemyTests.cs              два примера; остальные пишете вы
```

## Порядок работы

1. Развернуть заготовку, проверить `dotnet run` и `dotnet test` — это первый коммит.
2. Дальше по этапам, каждый этап — отдельный коммит.
3. **Этап 2 — два коммита**: сначала падающий тест на поверхностное копирование,
   потом исправление. Оба должны остаться в истории.

## Шаблон отчёта

- **Вариант** — номер, вселенная, клонируемая сущность, вложенный уровень.
- **Этап 0** — число классов; чем они отличаются; почему фабрика это не решает.
- **Этап 1** — устройство реестра прототипов.
- **Этап 2** — какие поля копируются глубоко, какие нет и почему; разбор `ICloneable`;
  ссылки на оба коммита.
- **Этап 3** — демонстрация добавления вида через JSON без перекомпиляции;
  что перестал ловить компилятор.
- **Этап 4** — таблица сравнения и ответ «когда оставить фабрику».
- **Диаграмма** классов в Mermaid.
- **Чем платим.**
