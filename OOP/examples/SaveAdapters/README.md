# Лабораторная работа 5 — заготовка

Стартовый проект к лабораторной [«Адаптер: подружить несовместимое»](../../labs/05-adapter-podruzhit-nesovmestimoe.md).
Здесь лежит код этапа 0: игровое меню работает с легаси-хранилищем напрямую,
знает про номера слотов, формат строки и коды ошибок.

## Как забрать себе

Скопируйте содержимое этой папки в свою работу — целиком, вместе с `tests/`:

```bash
git clone --depth 1 https://github.com/radilov-spsu/materials.git /tmp/materials
cp -r /tmp/materials/OOP/examples/SaveAdapters/. <ваш-репозиторий>/OOP/lab-05/
```

Без git: на [странице материалов](https://github.com/radilov-spsu/materials)
**Code → Download ZIP**, распаковать, взять папку `OOP/examples/SaveAdapters`.

Развёрнутая заготовка — ваш **первый коммит**, до единой собственной правки.
Тогда в истории видно, что написали вы, а что было дано.

## Как запустить

```bash
dotnet run --project src/SaveAdapters      # сохранение и загрузка через легаси-систему
dotnet test                                # тесты

cd python && python -m pytest              # часть этапа 3 (адаптер классов)
```

Нужен .NET SDK 8.0 или новее. Если стоит только .NET 9/10, запуск всё равно
сработает:

```bash
DOTNET_ROLL_FORWARD=LatestMajor dotnet run --project src/SaveAdapters
DOTNET_ROLL_FORWARD=LatestMajor dotnet test
```

Для этапа 3 нужен Python 3.11+ и pytest.

## Структура

```
src/SaveAdapters/
    Program.cs                    точка входа
    SaveMenu.cs                   ← код этапа 0: адаптация размазана по игровому коду
    Domain/SaveGame.cs            модель сохранения
    Domain/ISaveStorage.cs        контракт игры — к нему всё и приводим
    Domain/SaveExceptions.cs      исключения предметной области
    Foreign/LegacySaveSystem.cs   ЧУЖОЙ КОД — синхронный, слоты, коды ошибок
    Foreign/CloudStorageSdk.cs    ЧУЖОЙ КОД — байты, коллбэки, статус-коды
tests/SaveAdapters.Tests/
    SaveMenuTests.cs              два примера; остальные пишете вы
python/
    adapter_class.py              заготовка адаптера классов
    test_adapter_class.py         заготовка теста
```

⚠️ Файлы в папке `Foreign/` помечены как чужой код. **Менять их нельзя** — в этом
весь смысл работы. Правка такого файла — минус 15 баллов.

## Порядок работы

1. Скопировать папку себе и проверить `dotnet run` и `dotnet test` — первый коммит.
2. Дальше по этапам, каждый — отдельный коммит.
3. Для этапа 2 тесты оформляются как `[Theory]` и прогоняются против обоих адаптеров.

## Шаблон отчёта

- **Вариант** — номер, вселенная, две чужие системы.
- **Этап 0** — список мест, где игровой код знает детали легаси; что сломается
  при подключении облака; какой принцип нарушен и какой это запах.
- **Этап 1** — четыре вида перевода, которые делает ваш адаптер.
- **Этап 2** — три вида несовместимости; почему третье хранилище не затронет игру.
- **Этап 3** — адаптер классов на Python; что получилось в C# и чего не хватает.
- **Этап 4** — таблица «соседи по форме»; адаптер против моста.
- **Диаграммы** обоих адаптеров, раздел «чем платим».
